# Kappezette\Endpoints

![Checks](https://github.com/vojtech-dobes/php-kappezette-endpoints/actions/workflows/checks.yml/badge.svg?branch=master&event=push)

This library provides collection of tools to create HTTP API in Nette Framework.



## Installation

To install the latest version, run the following command:

```
composer require vojtech-dobes/kappezette-endpoints
```

Minimum supported PHP version is 8.4.
